## 2023-10-27 - Python File Traversal Bottlenecks
**Learning:** Treely's bottleneck in `os.listdir` combined with manual `Path.stat()` calls for each item was causing an excessive number of system calls, resulting in a ~0.85s load time for a 100x100 directory structure. Replacing it with `os.scandir()`, which caches stat results during iteration, yielded a 5x performance improvement (~0.16s).
**Action:** When working on Python tools that heavily traverse directories or query file attributes (like file tree generators or linters), default to using `os.scandir()` instead of `os.listdir()` to automatically leverage OS-level stat caching and minimize redundant system calls.
